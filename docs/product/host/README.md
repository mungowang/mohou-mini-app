# Host

Index: [features.md](../features.md).

Host owns app lifecycle, compile, history, events, HTTP, config, storage files, install, diagnostics, and the platform-module files. It does not construct a model provider and it does not render the panel. In-process calls exist. The loopback routes in [http.md](http.md) are mounted when Host starts.
